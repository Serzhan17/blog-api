HW3 — ГОТОВЫЙ ПРОЕКТ И ШАГИ (Windows CMD)

1. Распакуй архив в:
C:\Users\bakzhan.04\OneDrive\Рабочий стол\django
Архив уже содержит папку hw3. Проверь, что manage.py находится прямо в django\hw3,
а не в django\hw3\hw3. Не копируй внутреннюю папку целиком внутрь репозитория.

2. Открой CMD. Подготовь ветку в существующем репозитории:
cd /d "C:\Users\bakzhan.04\OneDrive\Рабочий стол\django\blog-api-submit"
git status --short
Если команда показала изменения, сначала сохрани текущую работу отдельным коммитом.
Далее:
git switch main
git pull --ff-only origin main
git switch -c hw3
Если hw3 уже существует, вместо последней команды: git switch hw3

3. Скопируй содержимое подготовленного проекта. Точка — это текущая папка!
robocopy "..\hw3" "." /E /XD .git .venv venv __pycache__ .ruff_cache logs /XF .env *.sqlite3 *.pyc /R:1 /W:1
Robocopy может вернуть код 1 при успешном копировании — это нормально.
Проверь:
dir manage.py

4. Подготовь окружение (Python 3.12):
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements/dev.txt
python setup_local.py
python manage.py migrate

5. Создай демонстрационные данные с правильными датами:
python manage.py seed --clear
ВНИМАНИЕ: --clear удаляет существующие посты, комментарии, категории, теги и обычных
пользователей; superuser сохраняется. Если нужны прежние данные, используй seed без
--clear, но доля 30% относится только к новым постам.

6. Запусти проверки:
python manage.py queries
python manage.py queries --number 31
python manage.py queries --number 6 --sql
python manage.py queries --number 24
python manage.py queries --number 26
python manage.py test
ruff check .
Ожидается: 30 тестов, OK. После seed --clear: #24 — 30 rows, #26 — 0 rows.
Запросы 40–44 меняют данные, поэтому запускаются только по номеру. Например:
python manage.py queries --number 41
Он опубликует старые черновики. Для восстановления данных: python manage.py seed --clear
Сервер и браузер для HW3 не нужны: результаты выводятся в терминале.

7. Посмотри изменения и отправь обе ветки:
git status --short
git add .
git commit -m "Complete Homework 3: ORM queries and realistic seed dates"
git push -u origin hw3
git switch main
git merge hw3
git push origin main
Ветку hw3 НЕ удаляй. При конфликте Git остановись и разбери конфликт до push.
